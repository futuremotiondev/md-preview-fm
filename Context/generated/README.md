## How to regenerate

### Slash command (preferred)

Invoke `/refresh-context` from the Claude Code prompt. Runs every regenerator listed in `.claude/context-engine.psd1` and reports diffs against the previous version.

### Direct invocation

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File Context/scripts/<regenerator>.ps1
```

### Automatic regen

The `PostToolUse` hook does **not** regenerate these artifacts on every save — that's a deliberate choice. Invoke `/refresh-context` at meaningful boundaries (after adding public surface, before a commit, during review).

## Banner format

Every generated file starts with three HTML comment lines:

```markdown
<!-- GENERATED FILE — DO NOT EDIT — regenerated by Context/scripts/<name>.ps1 -->
<!-- Source: <what it walks / parses> -->
<!-- Last run: <ISO-8601 UTC timestamp> -->
```

Check the `Last run:` timestamp to see how stale the index is. If it's older than the most recent commit that modified the source tree, regen.
