# MD Preview FM Layout

The repository's top-level layout, what each part does, and whose code it is. The Origin column is the practical guide to what this fork may edit: fork-owned files are fair game for presentation work, upstream-owned files stay close to [vorojar/md-preview](https://github.com/vorojar/md-preview) so its releases merge cleanly.

For how the pieces run together (startup sequence, render pipeline, IPC, on-disk state), read [dev-docs/architecture.md](../../dev-docs/architecture.md).

## Crate

A single binary crate, `md-preview-fm` (edition 2021, no `lib.rs`, no workspace).

| Path              | Role                                                                                                                                                                    | Origin                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `src/main.rs`     | Nearly everything: window, WebView, Markdown rendering, the whole HTML/CSS/JS UI as a string in `build_page()`, IPC, file watching, updater, OS integration, unit tests | Upstream, with fork edits (identity, theme and font inclusion, `embed_local_images` for HTML `<img>`) |
| `src/session.rs`  | Tab model (`DocumentSession`, `DocumentTab`) and `session.json` persistence                                                                                             | Upstream                                                                                              |
| `src/instance.rs` | Single-instance launch forwarding over a localhost socket guarded by `instance.lock`                                                                                    | Upstream                                                                                              |
| `build.rs`        | Windows version resource and exe icon via `winresource`                                                                                                                 | Upstream, fork metadata                                                                               |
| `Cargo.toml`      | Package identity, dependencies, size-optimized release profile (`opt-level = "z"`, LTO, `panic = "abort"`)                                                              | Fork identity on upstream's manifest                                                                  |

## Compiled-in assets

Everything under `assets/` is embedded with `include_str!` / `include_bytes!`, so a change shows up only after a rebuild.

| Path                                            | Role                                                                                                          | Origin                                  |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| `assets/theme/futuremotion-theme.css`           | The fork's stylesheet: `--fm-*` tokens plus overrides, loaded after upstream's inline CSS                     | Fork                                    |
| `assets/theme/futuremotion-fonts.css`           | Inter and JetBrains Mono as base64 WOFF2, generated by `scripts/build-theme-fonts.py`                         | Fork, generated                         |
| `assets/theme/FONTS-LICENSE.md`                 | Licenses for the embedded fonts                                                                               | Fork                                    |
| `assets/enhance/preview-enhance.js`             | Page-side enhancement: table wrappers, alerts, math, Mermaid, anchor links                                    | Upstream, fork edit (wraps every table) |
| `assets/enhance/update-check.js`                | Page-side GitHub release check and Update button                                                              | Upstream, fork asset name and repo      |
| `assets/hljs/`                                  | `highlight.min.js` and the Delphi pack (vendored), plus the light and dark syntax themes the fork may restyle | Vendored scripts, editable themes       |
| `assets/katex/`, `assets/mermaid/`              | Math and diagram renderers, injected only when a document needs them                                          | Vendored                                |
| `assets/icon.ico`, `icon.icns`, `icon_1024.png` | Exe resource icon, window icon, README image                                                                  | Upstream                                |

## Tooling, CI and docs

| Path                                                                          | Role                                                                                                                                   | Origin                       |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| `scripts/build-theme-fonts.py`                                                | Converts the local TTFs in `app-reference/fonts` into `futuremotion-fonts.css`                                                         | Fork                         |
| `scripts/verify*.{sh,mjs,ps1,py}`, `release.sh`                               | Upstream's verification gate and release helper; `verify-windows-startup.ps1` runs in CI                                               | Upstream, fork-adjusted      |
| `scripts/*appcast*`, `fetch-sparkle.sh`, `generate-app-store-screenshots.mjs` | macOS Sparkle updates and App Store screenshots                                                                                        | Upstream, unused by the fork |
| `.github/workflows/`                                                          | `ci.yml` (Windows and Linux build and test, WebView2 startup, PE subsystem and icon checks) and `release.yml` (publishes on `v*` tags) | Fork                         |
| `dev-docs/`                                                                   | Fork developer guides: styling, build and branding, runtime architecture                                                               | Fork                         |
| `CHANGELOG.md`                                                                | Fork changelog from 1.0.0; `release.yml` takes release notes from it                                                                   | Fork                         |
| `README.md`                                                                   | Fork README                                                                                                                            | Fork                         |
| `LESSONS.md`, `task.md`                                                       | Upstream's pitfall notes and task log, in Chinese; not this fork's roadmap                                                             | Upstream                     |
| `Context/`, `.claude/`, `.githooks/`                                          | Context engine: knowledge tree, session and edit hooks, slash commands, commit-msg hook                                                | Context engine               |

## Other platforms and leftovers

| Path                                                   | Role                                                                                  | Origin               |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------- | -------------------- |
| `mobile/`                                              | Separate iOS and Android apps with their own CSS (`mobile/shared/mobile-preview.css`) | Upstream, left alone |
| `macos/`, `bundle.sh`, `release-sign.sh`, `install.sh` | macOS app bundle, Finder extension and signing; the fork doesn't build macOS          | Upstream, left alone |

| `screenshots/`                                         | `hero.jpg`, `welcome.png` from upstream's website                                     | Upstream             |
| `app-reference/`                                       | Git-ignored local material, including the font source TTFs                            | Local only           |
| `target/`                                              | Cargo build output                                                                    | Generated, ignored   |
